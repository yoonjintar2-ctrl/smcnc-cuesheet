# SM C&C 큐시트 툴 (온라인판)

TV 큐시트(지상파·케이블) 입력 → 요약 · 전체 큐시트 · 지상파/케이블 큐시트를 만드는 도구의 온라인판입니다.

- 사이트: https://yoonjintar2-ctrl.github.io/smcnc-cuesheet/
- **뷰어**: 캠페인 링크(`?c=캠페인코드`)로 들어오면 운영사항(예산·소재)과 큐시트만 볼 수 있어요. 아무것도 고칠 수 없어요.
- **관리자**: 오른쪽 위 '관리자 모드 접속' → 비밀번호. 지금과 같은 편집 화면이 열리고, 고친 내용은 바로 온라인(Supabase)에 저장돼요.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 앱 (빌드 결과 — `python build.py` 후 `dist/web/index.html`을 복사) |
| `config.js` | Supabase 주소 · 공개 키(publishable) — 브라우저에 보여도 되는 값 |
| `supabase/schema.sql` | Supabase에 넣은 표·함수 (`cue_` 로 시작 · RLS로 표는 막고 함수로만 읽고 씀) |
| `src/`, `lib/`, `build.py` | 소스 (단일 HTML로 묶어 빌드) |

## 데이터 보호
- 표(`cue_ws` 등)는 RLS로 모두 막혀 있어 공개 키로 직접 읽을 수 없어요.
- 뷰어는 캠페인 코드를 아는 사람만 그 캠페인을 읽을 수 있어요 (`cue_view*` 함수).
- 저장은 관리자 비밀번호(DB에 bcrypt 해시)로 받은 세션 토큰이 있어야 해요 (12시간, 쓰면 연장).
- 비밀번호 바꾸기: Supabase SQL 편집기에서 `schema.sql` 맨 아래 줄의 비밀번호만 바꿔서 실행.

## 오프라인판
같은 소스로 만든 `코웨이TV큐시트.html`(config.js 없이 열면)은 지금처럼 이 컴퓨터 브라우저에만 저장하는 모드로 돌아가요.
