두 가지로 돌아가요.
- **온라인판** (https://yoonjintar2-ctrl.github.io/smcnc-cuesheet/) — GitHub 저장소 `yoonjintar2-ctrl/smcnc-cuesheet`의 `index.html` + `config.js`(Supabase). 코웨이 전용(`config.js`의 `camp`). 링크로 들어오면 뷰어(보기만), 관리자는 **개별 계정(회사 이메일 + 비밀번호)**으로 편집(15차). 데이터는 Supabase **yoonjintar0 계정 · `yoonjintar0@gmail.com's Project`**(jiaqobfriamuxtvxhrls)의 `cue_` 표(함수로만 읽고 씀 — `web/supabase/schema.sql`). 2026-10-03에 campaign-dashboard 프로젝트에서 옮김.
- **오프라인판** `코웨이TV큐시트.html` — config.js 없이 열면 지금처럼 이 컴퓨터 브라우저에만 저장.

이 폴더(`_개발`)는 고칠 때만 필요합니다.

## 고치는 순서
1. `src/` 안의 파일을 고칩니다. (`코웨이TV큐시트.html`을 직접 고치지 마세요.)
2. `python build.py` → `dist/코웨이TV큐시트.html`이 새로 만들어집니다.
3. 새 파일로 기존 `코웨이TV큐시트.html`을 덮어씁니다. 브라우저에 저장된 작업·이력은 그대로 남습니다.
4. 온라인판: `dist/web/index.html`을 GitHub 저장소 `smcnc-cuesheet`의 `index.html`로 올리면 1~2분 뒤 반영돼요.

## 15차 (2026-10-06)
- **요약 순서**: KPI → 운영 요약 → 품목별·방송사별 예산·보너스 → 예산 및 보너스 표 → 정사각형 4칸(초수별 노출수 · 요일별 노출수 · 지상파 중CM 비중 · 케이블 중CM 비중 — 3D 도넛, 초수·요일은 전체/지상파/케이블) + 중CM·PIB 막대 → 송출 횟수 → 주차별 송출 수 → 당월 소재.
- **표 디자인 통일**: 머리글 진회색·흰 글씨, 소계 옅은 회색 굵게, 합계 진회색·흰 글씨(모든 결과 표). 두 줄 머리글은 둘째 줄 위치를 첫 줄 높이에 맞춤(`syncStickyHeads` — 송출 횟수 단차).
- **운영 요약**: 같은 카테고리는 첫 열 병합, 품목 요약 줄 이름은 B~C 병합(방송사 칸 비움), 합계는 A~C 병합, 주요 프로그램만 왼쪽 정렬. 품목별 리치 곡선은 표 위 '요약 리치 곡선' 창에서.
- **품목 막대**: 예산·보너스가 맞닿는 쪽은 각지게, 보너스 레이블도 품목 색. **방송사 도넛**: 바깥 점선 호로 지상파/케이블 표시, 표의 색 네모는 없앰. **주차별 송출 수**: 숫자는 막대 끝 오른쪽.
- **큐시트**: 주차 칸 글자 흰색 · 지상파 “[품목] 소재 초수”, 케이블 “[품목] 초수 CM위치”(값 항목 고르기 없앰). 지상파 큐시트는 주차 칸·CM 순서·집행일자 등을 좁혀 필요할 때만 두 줄(1500px 화면 기준 1975 → 1770px). 방송사 계·3사 계는 더 진하게.
- **메뉴 이름**: 입력 → **규칙 관리**(품목·채널·CM위치 보정 규칙·목표 CPRP — 매칭 규칙 메뉴는 없앰), 당월 운영 → **당월 입력**(당월 예산·당월 소재·지상파 입력·케이블 입력·리치 입력).
- **추가·수정한 사람·일시**: 채널 관리·CM위치 보정 규칙·목표 CPRP의 '이번 달' 열 대신 '추가·수정' 열(마스터 행 끝 `by`·`at` 칸 — 채널 [5][6], CM위치 [2][3], 목표CPRP [3][4]). CM위치의 마스터에 없는 표현은 목록만 보여 줌(추천·추가 단추 없음).
- **지상파·케이블 입력**: 끝에 '입력 일시'·'입력자'(자동 — 온보딩으로 넣거나, 붙여넣거나, 빈 행에 처음 쓸 때. 손으로 못 고침, 내용을 다 지우면 같이 비움). 잘못 온보딩한 것을 일시로 찾을 수 있음.
- **방송사 큐시트 온보딩**: 먼저 '지상파 입력 / 케이블 입력'을 고름 → 그 시트 편집 잠금을 잡아 다른 관리자와 겹치지 않음(고른 매체가 아닌 시트는 '이번엔 안 넣어요'). 매칭 규칙은 창 위쪽에서 펼쳐 고치고 추가(＋). 확인 카드는 고르기 · ＋새로 추가(접힘) · 다음부터 자동(접힘)만. 파일 없이 닫으면 남던 ‘엑셀 파일을 놓으세요’ 덮개 고침.
- **관리자 개별 계정**(`schema15.sql`): 이메일 아이디 + 비밀번호(bcrypt 해시만 저장). 처음(또는 초기화 뒤) 접속하면 새 비밀번호를 두 번 넣어 바꾸기 전에는 아무것도 못 함. 관리자 메뉴: 내 설정(비밀번호 바꾸기) · 관리자 계정(목록 · 새 관리자 초대 = 초기 비밀번호로 바로 계정 생성 · 비밀번호 초기화 · 빼기) · 운영 누적 메뉴 보이기 토글. 초대 메일은 보내지 않음. 저장·잠금의 '누가'는 계정 이름.

## 계산 규칙 (기존 엑셀과 같게 맞춘 것)
- 지상파 밸류 = 예산 + 보너스 스팟(금액 0) 단가 합 / 케이블 밸류 = 단가×횟수 합, 보너스 = 밸류 − 예산
- eq.GRP = 예산 ÷ 목표 CPRP(15초 기준) — 지상파는 채널, 케이블은 **채널 이름 행이 있으면 그 값 → 없으면 PP(MPP) 값**(1~2월 엑셀은 같은 PP 안에서도 채널마다 달랐음). GRP = eq.GRP × Σ(초수별 **계획 예산 비중** × 15/초수) — 엑셀처럼 품목마다 비중 하나를 모든 채널에 씀(예전 달처럼 지상파·케이블 비중이 다르면 `WS.secPlan['품목|지상파']`·`['품목|케이블']`, 소재 탭에 '지상파만'·'케이블만' 줄로 보임). 비중은 소재 탭 'GRP 계산 초수 비중'(직접 입력, `WS.secPlan`) → 없으면 소재 금액 비중을 초수별로 합산 → 그것도 없으면 실제 송출 단가 비중
- CM 위치(엑셀 기준): 지상파는 엑셀 'CM 구분' 수식 그대로 — '중'으로 시작 = 중CM, 끝 글자 1·2·3·D·P = PIB(후TOP·전END와 ±1~3), 나머지 = 그외. 케이블은 마스터 'CM위치' 분류 값 그대로(중CM(하프) 등은 중CM 아님)
- 지상파 CM지정비: 예전 큐시트에서 지정율은 있는데 지정금액 칸이 비어 있으면 엑셀처럼 지정비 0 (변환할 때 지정율을 비고로 옮김)
- R1·R3 = 아리아나 누적리치 커브에서 GRP가 가장 가까운 지점 (품목 요약은 지상파 송출이 있으면 '지상파케이블', 없으면 '케이블' 커브 — 운영 요약의 품목 요약 줄에서 직접 고를 수 있음 = 엑셀 '수동 입력', `WS.opsCurve`). 커브는 R1·R3가 같은 구간의 처음·끝 점만 남겨 저장(찾는 결과는 원본과 같음, GRP 소수 넷째 자리까지). 운영 요약에서 직접 입력한 값(`WS.opsReach['품목|방송사' 또는 '품목|합계']`)이 있으면 그 값이 우선 — 작업 파일 '리치직접입력' 시트에 저장
- 지상파 정산: 연계 = (KBS+MBC 유상 금액)×20% + SBS 예산×10%, CM지정비 = 단가×지정율 (KBS 유상은 ÷0.85), 예비비 = 예산 − 유상 − CM지정비 − 연계
- 주차 = 월요일 시작, 달의 1일이 속한 주가 1주

## 저장 형식 메모
- 숨긴 행은 작업 파일 엑셀에서도 '숨겨진 행'으로 저장돼요. 엑셀에서 숨김을 풀고 보내면 이 도구에서도 풀려요. 숨긴 행도 집계에는 들어가요(엑셀과 같음).
- 케이블 큐시트에서 끌어서 바꾼 프로그램 순서는 작업 파일의 '케이블순서' 시트에 저장돼요.
- 집행 시작일·종료일 입력은 없앴어요. 항상 그 달 1일~말일 기준이에요.
- 방송사 원본을 넣으면 1행 1송출로 들어가고, 케이블 '구분'에는 Q-Mate 보정값(중CM/PIB/전후CM)이 들어가요. 지상파는 Q-Mate처럼 품목 미지정, 금액은 원본의 방송금액(실집행금액) 열을 읽어요(0·빈칸 = 보너스).
- 엑셀 붙여넣기는 머리글 행을 보고 열을 맞추고, 예전 가로형 지상파 표도 바로 변환해요(구분은 행마다 채움). 엑셀이 같이 주는 HTML의 실제 값(x:num)으로 반올림된 숫자를 되돌려요.
- 예산 시트에 품목 이름·집행기간 같은 줄이 채널로 들어가 '마스터에 없는 채널'로 뜨던 것: 예전 통합 큐시트 변환기(tools/legacy.js)가 예산 블록 아래 품목별 집행기간 블록까지 읽던 문제 — 고쳤고, 온라인 7~10월 데이터에서도 지움.
- 지상파 '구분'(정기물 등)은 행마다 적어요. 예전 데이터는 처음 열 때 같은 채널 안에서 아래 행으로 이어 채움(`kindV`).
- 지상파·케이블 입력 화면: 오른쪽 카드(실시간 집계·선택 행·확인 필요)는 없앴어요. 필터를 걸면 표 위에 '필터 결과'(송출 횟수·단가 합·유상 금액·채널×품목 예산)와 머리글 위 합계 줄이 보여요. 확인 필요 목록은 점검 > 확인 필요에 있어요.
- 누적리치: 엑셀처럼 그룹 블록(1행 그룹 이름 + Cume GRP·Reach1+·Reach3+)이 옆으로 나란히. 블록을 누르고 Ctrl+V(머리글째 OK) → 다음 빈 블록으로 넘어감. 좌우 이동은 스크롤바 대신 ‹ › 단추·방향키. '8개 그룹 한 번에 붙여넣기'도 그대로.
- 품목 이름은 약칭만 씀(별칭 없음). 정식명·예전 별칭으로 적힌 곳은 집계에서 빠지고, 화면 위 노란 줄 + 검증 오류로 알려 줌 → '모두 약칭으로 고치기'. 예전 별칭은 `WS.itemLegacy`에 보관(알림용).
- 전체 큐시트 다운로드 열: No · 구분 · 방송사 · 품목 · 편성명 · 날짜(yyyy-mm-dd) · 요일 · 시작시간 · 종료시간 · 초수 (+ 고른 추가 열: 소재·CM 위치·시급·단가)
- 엑셀 받기(⤓)의 메뉴별 파일도 같은 보고용 서식이에요. 숨긴 데이터 시트는 엑셀에서 '숨기기 취소'로 볼 수 있어요(지우지 않으면 다시 넣기 가능).
- 작업·백업 엑셀의 `_meta` 시트에 집행 시작·종료일과 광고주도 적어요(지난 달 백업을 통째로 되살릴 때 씀).

- 엑셀 '운영 요약' 상단 표를 기준값으로 맞춤: 달마다 다른 목표 CPRP(금액 ÷ eq.GRP로 역산) · GRP 초수 비중 · R1/R3(누적리치 시트가 없는 1~6월은 엑셀 값을 '직접 입력'으로) · 주요 프로그램 문구(엑셀 그대로).
- 1~2월 케이블은 단가가 없어서 편성(채널·프로그램·요일·시작·CM)마다 15초 단가 하나를 정해 채널×품목 합계를 엑셀 방송 Value에 맞춤(같은 편성은 같은 단가 · 초수 비례). 일부 채널은 끝수 몇 원이 남을 수 있음.
- 대조 결과: 3~9월은 운영 요약 표(금액·횟수·GRP·eq.GRP·R1·R3) 전부 일치. 1~2월은 예산·횟수·CM 위치·보너스·R1/R3 일치, '기타' 그룹 GRP는 채널별 CPRP를 알 수 없어 기본값으로 계산(±1~12%). 엑셀 쪽 수식 오류로 보이는 칸(품목 하나만 CPRP가 다르거나 방송 Value에 예산이 빠진 칸)은 따라 하지 않음. 자세한 대조 결과는 프로젝트 문서에.
